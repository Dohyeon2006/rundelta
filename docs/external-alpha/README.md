## 范围与盲法

只读取 issue 正文、状态/标签、许可证、贡献规范和复现所需文件；未读取 issue 评论、PR 讨论、commit discussion。三例均经 issue API 确认 open，且被 `is:issue is:open -linked:pr repo:OWNER/REPO NUMBER` 搜索返回。正文没有已知修复 PR。此筛选排除了正式关联 PR，但不能证明不存在未关联或尚未索引的修复；未通过阅读讨论进一步排查。

- pybind11：BSD 风格许可证，阅读 `.github/CONTRIBUTING.md`。
- SPAdes：GPL-2.0 许可证；根目录及标准 `.github`/根 CONTRIBUTING 路径未发现贡献文件。使用官方 4.0.0 Linux 发布包，另有只读 v4.0.0 源码 checkout。
- Meson：Apache-2.0；阅读 `contributing.md` 及其指向的贡献规范。使用正文附件原样解压，不改任何文件。

各目录的 `CASE.md` 是首次运行前保存的登记文本，校验值为原文 SHA-256。SPAdes 两次重试分别另存事前登记，没有覆盖最初方案或记录。登记中的 “Body conditions” 简写同时描述了实验对照；**pybind11 的正常前缀设置是本次设计的正常控制，不是作者声称存在过的历史成功记录**。本目录病例均不是此前的 pybind11 #5626 受控头文件漂移实验。

## 事实与解释边界

- 事实：真实目标退出码、调用参数、事件中的访问结果、运行元数据、原始证据行号，以及 RunDelta 自己报告的可靠性状态。
- 推断：环境前缀、空格路径条件可能缩小问题范围；需专门控制实验或源码分析才能归因。
- 无法证明：文件内容相同、未采集行为不存在、目录物理身份、完整运行环境一致、第三方内部逻辑根因、未来版本仍有此问题。
- Meson、SPAdes 的共享文件系统状态/CWD 告警没有被隐藏。`completed` 是记录生命周期状态，**不等于采集完整**。`diff=3` 的“不完整但可浏览观察差异”行为正确，不能改报 1。
- pybind11 的第 2 名依赖 `record --env CMAKE_PREFIX_PATH` 的事先选择，不能当作自动识别任意隐藏环境变量的能力。

## 材料与复算

每例包含 `CASE.md`、`RESULTS.md`、脱敏 `summary.json`、少量 `evidence-excerpts.json`。摘要保留产品原顺序的前五及明确标注的后排样本；它不是完整 JSON 报告，也不能重建全部差异。原始完整 JSON、正常/失败输出和 strace 仅留在隔离工作目录，没有复制到仓库。

公开摘录解码了 strace 的十六进制字符串，再替换工作目录/工具链前缀、PID 和地址；保留原始日志文件和行号。它是**变换后的有限证据**，不是字节级原日志。重新运行会产生新的 PID、临时名、行号、排名和总数；本次数字不能成为跨机器硬断言。

见 [REPRODUCE.md](REPRODUCE.md)。`verify.py` 检查文件白名单、冻结登记、摘要内部一致性和明文/转义后私有路径；不读取或修改旧记录。

## 建议

1. **不足以支持“真实项目有效线索稳定进入前五”的公开 alpha 声称。** 可以作为限定范围、明确不完整状态的探索性诊断证据；不能宣称已验证普遍定位能力。
2. 本轮未确认新的数据损坏、虚假可信路径或退出码缺陷。应先评估已有共享文件系统/CWD 覆盖边界，它影响了两例；不以取消告警恢复“完整”。同时用新的独立样本验证命令不同带来的混杂，暂不按这三例调排序。
3. SPAdes 最值得进入下一阶段的**独立根因验证**：先固定解释器和输出路径，分别改变安装与工作目录，再检查配置生成/解析边界。当前 exec 证据中的配置路径是单个参数，没有证据支持 shell 拆词根因。确认后再评估贡献是否有价值；本轮没有对外操作。
4. Meson 的失败可以复现，但 RunDelta 不提供 bar 内部依赖映射事实；优先判断支持边界和项目语义，不直接承诺补路径模型或排序就能解决。pybind11 更像包发现配置问题，不足以认定上游代码缺陷。

## 独立重放中的额外不确定性

SPAdes 的第二阶段成功运行 `bad-v2` 在重放中新增 `unfinished call at end of trace` 告警（原始第 24101 行）。实际追踪是 `???( <unfinished ...>`，同一 PID 第 24107 行正常退出；本轮没有识别这个 syscall，也未证明它是 RunDelta 解析器缺陷。目标仍退出 0，存储仍 verified，采集仍 incomplete，diff 仍为 3。全部告警及两行脱敏证据保留在 [REPLAY.json](REPLAY.json)。新增的一条 Capture completeness 差异解释了总数 6287→6288，不能仅归为无害临时文件噪声。后续应独立复现并分类这条未知调用，不能删除告警使报告“完整”。
