# Pre-run protocol
Three primary comparisons: baseline initial A/no child, shared pthread with parent changing CWD to B before child relative open, fork child with parent changing CWD to B before child relative open. A and B contain identically named files with distinct marker bytes. Reader signals ready before parent changes CWD; parent signals done only after success/failure recorded; reader waits done before any file access. All threads/processes joined before root exit. Repeat each case three times.
Additional controls: shared pthread without CWD change; shared and fork fchdir; failed chdir/fchdir; clone(CLONE_FS|SIGCHLD) without CLONE_THREAD; access() relative paths without descriptor annotation. First observe, do not change product semantics or ignore warnings.
Expected: shared read B, fork read A, failed switch read A. No physical-absolute claim should be made from historical CWD. Record exact normalized paths, cwd_before, context_uncertain, raw lines and reliability. Open-only baseline and fork may be complete; shared cases may remain partial even when returned FD evidence locates the file. Unannotated access may remain relative/uncertain in both. No ranking evaluation or alpha relabeling.
Mixed-group scope control (registered before first record): fork the reader while FS is unshared; later create and join an unrelated pthread in the parent; parent changes CWD. Reader should still read A. This isolates run-global warning/context loss from actual reader FS membership.
