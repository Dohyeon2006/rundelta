## 测试与适用边界

实际执行：8 个独立脚本单元测试全部通过；六组实际审计覆盖全部原索引恰好一次、分组详情包含所有相关标准化事件及证据、可靠性不变、预登记异常前五可见。R1 的真实组展开事件数见 RESULTS.json。审计对原始 JSON 及记录文件计算前后摘要，证明本次分析未修改它们。产品及原冻结文件另行与本阶段基线核对未变；没有重跑产品全套测试，因为没有产品改动。

合成测试不算真实案例。内容变化反例测试的“通过”表示成功展示不安全推论：相同路径结构/写入行为/父进程/调用次数仍可能写入错误内容。R2 仅有合成正反例，未有真实收益。未验证跨平台、不同工具版本、守护进程、PID 复用、复杂 namespace、动态 exec 的精确父进程匹配、恶意文件名或独立用户定位成功率。三个受控异常以显式访问失败为主，不能代表仅成功路径改变的全部风险。
